The Family suite — 5 characters × 4 outfits (20 rigs, 396 parts)

rig-c/parts-examples/family starts from one wide group illustration (1024×571 RGBA) upscaled with 4x-AnimeSharp to 4096×2284, decomposed with See-through in two passes (full + head), and rigged per character in four outfit sets (office, homewear, swimwear, uniform). Each rig's config pins its declared mesh and binding repairs (declared-repairs.json) by hash. The live demo links each rig's config.json and built model under the player.

From the repository root (Bun and Node on PATH), this rebuilds all 20 rigs from their configs and checks them against the stored outputs:

bun install --cwd family/tools/outline-field-islands --frozen-lockfile
node family/tools/verify-reproducibility.mjs --out /tmp/new-repro-evidence
bun family/tools/verify-accepted.mjs --out /tmp/new-family-evidence

rig-c/trailer — the 12-second short

rig-c/trailer is the loop on the landing page: a character on a swing breathes, tilts her head, smiles, kicks her legs, hops and waves, her twin tails following on physics chains — 240 frames at 20 fps, rebuilt from one painting, two See-through layer sets and agent-authored configs:

git clone https://github.com/rig-c/trailer && cd trailer
pip install -r requirements.txt
./build.sh
